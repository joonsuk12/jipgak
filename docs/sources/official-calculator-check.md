# 공식 계산 마법사 대조 (출시 전 검증, D-26 ①)

- **대조일:** 2026-11-25 ~ 2026-11-26
- **대상:** 주택도시기금 포털 "내집마련마법사"
  - 주택구입자금 계산마법사: https://nhuf.molit.go.kr/FP/FP08/FP0801/FP08010201.jsp
  - 주택전세자금 계산마법사: https://nhuf.molit.go.kr/FP/FP08/FP0801/FP08010101.jsp
- **방법:** 구입은 P01을 마법사에 직접 입력해 결과를 받았습니다. 전세는 마법사 페이지 스크립트에서 신혼가구 전용(`productgb = "Y"`)의 한도 비율·한도액·금리표 값을 읽었습니다. 나머지 사례는 이렇게 확인한 산식으로 계산했습니다.

## 불일치 원인: 구입자금 한도의 소액임차보증금(방공제)

원문 한도 산식은 "담보주택 평가액 × LTV − 선순위채권 − 임대보증금 및 **최우선변제소액임차보증금**"입니다. 집각은 이 소액임차보증금을 0으로 가정했고(`newlywed-purchase.md`), 공식 마법사는 입주 예정 지역별 금액을 뺍니다.

- P01 공식: 5억 × 70% − 5,500만(서울) = **2억 9,500만**
- 공식 마법사 안내: 한국주택금융공사(HF) 구입자금보증에 가입하면 이 공제를 하지 않습니다. 다만 **수도권 소재 아파트는 보증 가입이 불가**합니다(부부합산 연소득 4천만 원 이하이면서 3억 원 이하 아파트는 예외). 보증료는 연 0.05~0.3%이고 고객이 부담합니다.

## 그 밖에 확인한 것

- **"6개월 이상 무주택" 문항:** 신혼부부전용을 고르면 나오지 않습니다(디딤돌 일반용).
- **소득:** 공식 문항이 "상여금을 포함한 배우자 합산 연소득"이라 `income-and-assets.md`의 세전·총소득 기준과 같습니다.
- **DTI(구입):** 기존 부채는 "현금서비스 포함 신용 + 담보대출 총액"을 입력받습니다. 상환 예정 기존 주담대(중도금·전세자금대출 포함)와 예적금담보대출은 제외하고, **부채 추정금리 4.58%**(한국은행 고시, 2026년 9월 기준)를 적용합니다. 새 대출은 대출기간·거치기간·상환방법으로 계산합니다.
  - P01 공식 결과: 2억 9,500만 원, 30년 원리금균등 3.50% → 월 1,324,682원. 연 1,590만 원이므로 합산 6,000만 원 대비 약 26.5%로 DTI 60% 이내입니다.
