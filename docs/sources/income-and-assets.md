# 소득·순자산·자녀 산정 기준 (주택도시기금 공통)

- **원문**
  - 상품 안내: 구입 https://nhuf.molit.go.kr/FP/FP05/FP0503/FP05030601.jsp , 전세 https://nhuf.molit.go.kr/FP/FP05/FP0502/FP05020401.jsp
  - 자주하는 질문(소득·다자녀): https://nhuf.molit.go.kr/FP/FP05/FP0502/FP05020408.jsp ("연소득", "다자녀"로 검색)
  - 자산 심사 안내: https://nhuf.molit.go.kr/FP/FP08/FP0813/FP081301.jsp?id=20&mode=S&currentPage=1&articleId=1160
- **확인일:** 2026-11-18
- 두 상품(구입·전세)에 같이 적용되는 기준입니다. 상품별 기준값(소득 상한, 순자산 상한)은 각 상품 파일에 있습니다.

## 1. 연소득

원문 용어는 "대출신청인과 배우자의 **합산 총소득**"입니다.

| 소득 종류 | 산정 기준 (원문 요약) |
|---|---|
| 근로소득 | 최근 원천징수영수증, 소득금액증명원, 급여내역서 상 금액. **원천징수영수증 상 비과세소득은 제외** (= 세전 금액에서 비과세 수당을 뺀 값) |
| 근로소득, 재직 1년 미만 | 급여내역서 총액을 연 단위로 환산(월 환산). 한 달 이상 온전히 재직해야 함 |
| 일시적 증가(성과급, 내일채움공제 등) | 그래도 소득입증자료 상 금액 그대로 산정 |
| 사업소득 | 최근 사업소득 원천징수영수증, 소득금액증명원, 종합소득세 신고서(세무사 확인분) 상 금액. 사업 1년 미만이면 연 환산 불가 |
| 연금소득 | 연금수급 증명서(없으면 수령 통장) 금액. 1년 미만이면 월 환산 |
| 기타소득 | 소득금액증명원 금액. 1년 미만(이자 등)은 연 환산 불가 |
| 퇴사·폐업 | 이전 직장·사업장 소득은 인정하지 않음. 대출 접수일 기준 퇴직이면 소득 없음으로 간주 |

- **재직 확인:** 근로소득자는 건강보험자격득실확인서, 사업자는 사업자등록증으로 "현재 재직 중인 직장·영위 중인 사업" 기준으로 산정합니다.
- 전년도 자료가 아직 발급되지 않았으면 그 이전 연도 자료를 씁니다. 다만 근로소득은 전년도 원천징수영수증이 발급되면 전전년도 자료를 쓸 수 없습니다.

**엔진 처리:** 사용자가 계산한 연소득을 그대로 받습니다. 화면 안내는 "세전, 비과세 제외"로 합니다(용어집 참고).

## 2. 순자산

"대출신청인 및 배우자의 합산 부동산, 일반, 자동차 및 금융자산의 합계에서 금융부채 및 일반부채를 차감한 순자산가액"입니다.

| 구분 | 항목 | 산정 기준 |
|---|---|---|
| 자산 | 토지·건축물 | 지방세법상 **시가표준액** (시세가 아님) |
| 자산 | 임차보증금 | 임대차계약서상 보증금·전세금 (지금 사는 집의 전세금도 자산) |
| 자산 | 분양권 | 대출 접수일까지 낸 금액 |
| 자산 | 조합입주권 | 관리처분계획 가격 ± 청산금·추가부담금 |
| 자산 | 자동차 | 지방세법상 시가표준액 |
| 자산 | 요구불예금(입출금 통장) | 조회 기준일부터 과거 3개월 평균 잔액 |
| 자산 | 저축성예금, 예수금, ISA | 계좌 잔액 또는 총 불입액 |
| 자산 | 주식·펀드 등 | 조회 기준일 시세 |
| 자산 | 연금저축·퇴직연금 | 연금 개시 전 잔액 |
| 자산 | 보험 | 해약 시 환급금 |
| 자산 | 기타 | 선박·항공기·회원권·어업권·광업권 등 시가표준액 기준 |
| 부채 | 금융기관 대출 | 조회 기준일 잔액. **마이너스통장(한도대출)과 금융기관 외 금전거래는 제외** |
| 부채 | 신용카드 연체·미결제 | 3개월 이상, 50만 원 이상인 건 |
| 부채 | 공공기관·공제회 대출 | 증명서상 잔액 |
| 부채 | 상가·오피스텔 임대보증금 | 임대차계약서상 보증금 |

- 기준 시점: 부동산·자동차·일반자산·일반부채는 대출 접수일, 금융자산·금융부채는 사회보장정보원 조회 기준일(대략 접수 3개월 전 시점).
- 심사는 사전(일부 금융기관) → 사후(전체 금융기관) 두 번 합니다. 사후 심사에서 기준을 넘으면 가산금리가 붙거나(초과액 구간별) 1억 원 초과 시 기한이익상실(대출 회수)됩니다.
- 상한값은 매년 통계청 가계금융복지조사에 연동됩니다(구입 = 소득 4분위 평균, 전세 = 소득 3분위 평균).

**엔진 처리:** 사용자가 합산한 순자산을 그대로 받습니다. v1 입력 위저드에서 항목별 계산 도우미를 검토합니다(`docs/REVIEW.md`).

## 3. 자녀 (금리 우대)

- **다자녀가구:** 가족관계증명서 또는 주민등록등본상 신청인의 **만 19세 미만 자녀가 3인 이상**(세대 분리된 자녀 포함)
- 1자녀·2자녀 우대의 나이 기준은 원문에서 찾지 못했습니다.
- 2025-03-24 신규 접수분부터 자녀 1명당 일정 기간만 우대(구입 5년·최대 15년, 전세 4년·최대 12년)

**엔진 처리:** `children.count`(입력한 자녀 수)로 판정합니다. 신혼부부(혼인 7년 이내)의 자녀는 대부분 만 19세 미만이라 v1에서는 나이를 따지지 않습니다. 재혼 등으로 만 19세 이상 자녀가 있으면 다자녀 판정이 실제와 다를 수 있습니다.
