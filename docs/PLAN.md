# 집각 기획안

> "집 살 각 나오나?" — 신혼·예비부부를 위한 정책 대출·청약 자격 판정 서비스
> 작성: 2026-11-17

## 1. 한 줄 정의

소득·자산·혼인 정보를 넣으면 받을 수 있는 신혼부부 정책 대출(이후 특별공급)을 **조건별 근거와 함께** 판정하고, **무엇을 바꾸면 되는지(what-if)**까지 보여 주는 모바일 우선 서비스입니다.

## 2. 대상 사용자

- 혼인 7년 이내 신혼부부
- **결혼 예정인 예비부부** (혼인신고 시점별 유불리가 핵심 관심사)

## 3. 차별점

1. **조건별 통과/실패 근거:** 가능/불가만이 아니라 어느 조건에서 왜 걸렸는지와 원문 링크를 보여 줍니다.
2. **what-if:** 혼인신고 시점, 소득, 주택가격을 바꿔 보며 다시 판정합니다.
3. **개인정보 무전송:** 판정은 기기 안에서만 하고, 입력값은 기기 밖으로 나가지 않습니다.
4. **최신성:** 규칙을 데이터로 관리해 정책이 바뀌면 앱 업데이트 없이 반영합니다.

## 4. 범위

| 단계 | 범위 | 완료 기준 |
|---|---|---|
| **v0** | 모노레포(pnpm), 판정 엔진, 규칙 스키마, v1 대상 2개 상품 규칙, 골든 테스트, 데이터 어댑터 인터페이스와 static 구현, `config.json` | `pnpm test` 통과, 골든 케이스 전부 일치 |
| **v1** | 모바일 웹 화면(목적 선택 → 입력 위저드 → 결과 → 상세), Cloudflare Pages 배포(`*.pages.dev`), 분석(입력값 제외), 해설 글 몇 편, 개인정보 처리방침, 면책 문구 | 실사용자 피드백 수집 |
| **v2** | what-if, 신생아 특례 상품, 신혼 특별공급 자격, Capacitor Android 출시, `jipgak.kr` 도메인 연결, AdSense | Play 스토어 등록 |
| **v3** | 공고 수집 배치(Python)와 FCM 주제 푸시, 앱 내 재판정, iOS, 필요 시 FastAPI + 토글 전환 | 공고 알림 → 재판정 동작 |

## 5. 화면 흐름 (v1)

```
시작 → 목적 선택 (구입 / 전세 / 둘 다)
     → 입력 위저드 (혼인 상태·날짜 → 부부 소득 → 순자산 → 주택 보유·대출 이력 → 희망 주택 / 보증금·지역)
        * 모르는 항목은 '모름' 허용 → 결과에서 '확인 필요'로 표시
     → 결과 목록 (가능 / 확인 필요 / 불가)
     → 상세 (조건별 체크리스트, 근거 링크, 예상 한도, 예상 금리 범위)
```

## 6. 수익화 (v2 이후)

- AdSense(웹)와 AdMob(앱). 자체 도메인과 해설 콘텐츠가 있어야 승인됩니다.
- 특정 대출 상품 제휴·수수료는 하지 않습니다. 대출 모집·중개 규제를 검토하기 전까지는 금지입니다.
- 수익화 전에 회사의 겸업·대외 활동 규정을 확인합니다.
