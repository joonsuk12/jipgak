# 사용자 검토 항목

v0를 진행하면서 엔진이 임의로 정한 해석과 사용자가 결정할 일을 모았습니다. 항목마다 **현재 처리**를 적어 두었으니, 그대로 둘지 바꿀지만 정하면 됩니다. 결정하면 `docs/DECISIONS.md`에 옮기고 이 파일에서는 지웁니다.

- 작성: 2026-11-18
- 우선순위: **A** = v1 화면 전에 정해야 함, **B** = 출시 전까지, **C** = 나중에 해도 됨
- 결정 완료: 1-1 계약 전 판정, 2-1 전세 담보별 한도 → D-15 ("가능 + 안내")
- 원문 재검증으로 해결(2026-11-18): 2-2 다자녀 = 만 19세 미만 자녀 3인 이상(현재 처리와 일치), 2-5 자녀 나이 기준, 2-7 소득·순자산 산정 기준 → `docs/sources/income-and-assets.md`
- 결정 완료: 2-8 순자산 입력 방법 → D-18 (항목별 계산 도우미)
- 결정 완료: 1-2 계약일 모름, 1-3 규제지역 모름, 2-3 성년 세대주, 2-4 기금 구입대출 이력 → D-19 (2026-11-23)

## 1. 제품 결정

| # | 우선 | 항목 | 현재 처리 | 선택지 |
|---|---|---|---|---|
| 1-4 | C | **금리 범위 표시.** 구입자금은 대출기간(10~30년)에 따라 금리가 다릅니다. | 결과의 `rateRange`는 모든 기간의 최저~최고 금리이고, 우대는 자녀·청약저축만 반영합니다. 금리 방식 가산(+0.1~0.3%p)은 반영하지 않습니다. | ① 그대로 둔다 ② 기간을 입력받아 금리 하나만 보여 준다 |
