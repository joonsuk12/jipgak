# 골든 케이스

엔진의 기대 결과를 사람이 미리 정해 둔 사례입니다. `packages/rules-engine/test/golden.test.ts`로 그대로 옮깁니다.

- 기준일 `asOf = 2026-11-17`
- 금액 단위는 만 원입니다(코드에서는 원 단위로 변환).
- 값은 `docs/sources/`(2026-11-17 확인)에서 가져왔습니다.
- **상태: 2026-11-18 원문 대조 완료.** 아래 "원문 근거"의 기준값이 모두 원문과 일치합니다. 남은 검토는 제품 판단(입력 모름일 때 한도를 보여 줄지 등)뿐입니다.

공통 기본값: 세대원 전원 무주택, 주택 보유 이력 없음, 기금 구입·중도금 대출 이력 없음, 기금대출·주담대·전세대출 미이용, 공공임대 미거주, 매매·임대차 계약 체결. 표에 적힌 항목만 기본값과 다릅니다.

계약 체결 여부는 판정 상태에 영향을 주지 않고, 체결 전이거나 모르면 안내 문구만 붙습니다 (D-15).
