# 용어집

집각에서 쓰는 부동산·대출 용어를 정리했습니다. 각 항목은 세 부분입니다.

1. **💬 한 줄 안내:** 화면에서 입력 칸·결과 항목 바로 아래에 보여 주는 문장입니다(D-16). 사용자에게 하는 말투(해요체)로, 50자 안팎으로 씁니다.
2. **뜻:** "자세히"를 눌렀을 때 보여 주는 상세 설명입니다.
3. **집각에서는:** 엔진·규칙의 어느 필드인지 적은 개발자용 메모입니다. 화면에는 보여 주지 않습니다.

**★ 표시**는 한 줄 안내를 화면에 항상 보여 줄 용어입니다. 사용자가 잘못 입력하거나 오해하기 쉬운 것만 골랐습니다. 나머지는 "자세히"에서만 보여 줍니다.

- 정책 수치(한도, 소득 기준 등)는 여기 적지 않고 `docs/sources/`를 따릅니다. 이 문서는 개념 설명만 합니다.
- 화면의 도움말 문구를 쓸 때 이 문서를 원본으로 씁니다. 화면 문구로 옮길 때는 더 짧게 줄입니다.

## 1. 상품과 기관

**주택도시기금**
: 💬 정부가 운용하는 주택 지원 자금이에요. 시중보다 낮은 금리로 빌려줘요.
: 정부가 운용하는 주택 지원 자금입니다. 이 돈으로 시중보다 낮은 금리의 정책 대출을 해 줍니다.
: 집각에서는: v1의 두 상품이 모두 이 기금의 대출입니다.

**구입자금 / 전세자금**
: 💬 집을 살 때 빌리는 돈(디딤돌)과 전세금을 낼 때 빌리는 돈(버팀목)이에요.
: 집을 살 때 빌리는 돈과 전세 보증금을 낼 때 빌리는 돈입니다. 기금의 구입자금 상품군은 흔히 **디딤돌**, 전세자금 상품군은 **버팀목**이라고 부릅니다.
: 집각에서는: `loan-newlywed-purchase`(신혼부부전용 구입자금), `loan-newlywed-jeonse`(신혼부부전용 전세자금)

**수탁은행**
: 💬 기금 대출을 대신 접수·심사하는 은행이에요. 신청은 은행에서 해요.
: 기금 대출의 실제 접수·심사를 맡은 은행입니다. 사용자는 기금이 아니라 은행 창구나 앱으로 신청합니다.
: 집각에서는: 결과 화면의 "최종 확인은 수탁은행과 공고문에서" 문구가 이것입니다. 집각은 은행 심사를 대신하지 않습니다.

**HF / HUG 보증**
: 💬 전세대출을 보증하는 기관이에요. 보증 심사에 따라 실제 한도가 달라질 수 있어요.
: HF는 한국주택금융공사, HUG는 주택도시보증공사입니다. 전세대출은 이 기관들의 보증을 담보로 나가는 경우가 많고, 보증 심사 결과에 따라 실제 한도가 달라집니다.
: 집각에서는: 사용자가 입력할 수 없는 값이라 "직접 확인할 항목"으로 안내만 합니다.

## 2. 사람과 가구

**신혼부부 / 예비부부(결혼예정자)**
: 💬 혼인신고를 했으면 신혼부부, 아직 안 했으면 예비부부예요.
: 신혼부부는 혼인신고를 한 지 일정 기간 이내인 부부입니다. 예비부부는 아직 혼인신고 전이지만 곧 결혼할 예정인 사람입니다.
: 집각에서는: `marriage.status`가 `married`(혼인신고일 입력) 또는 `planned`(결혼 예정일 입력)입니다. 기간 기준은 `docs/sources/` 값을 씁니다.

**혼인기간** ★
: 💬 결혼식 날이 아니라 혼인신고일부터 세요.
: 혼인신고일부터 판정 기준일까지의 기간입니다. 결혼식 날이 아니라 **혼인신고일** 기준입니다.
: 집각에서는: 조건 연산 `withinPast`로 계산합니다.

**세대 / 세대주 / 세대원**
: 💬 주민등록등본에 함께 올라 있는 사람들이 한 세대예요.
: 세대는 주민등록상 한 집에 같이 사는 단위입니다. 세대주는 그 대표이고, 세대원은 세대에 속한 모든 사람입니다. 정책 대출 조건은 대부분 신청인 혼자가 아니라 **세대원 전체**를 봅니다.
: 집각에서는: "세대원 전원 무주택"처럼 `household.*` 입력으로 받습니다.

**무주택** ★
: 💬 등본에 함께 올라 있는 사람 모두 집이 없어야 해요. 분양권도 집으로 볼 수 있어요.
: 세대원 누구도 집을 갖고 있지 않은 상태입니다. 상품에 따라 분양권(새 아파트를 받을 권리)도 주택으로 봅니다.
: 집각에서는: `household.allHomeless`

**생애최초** ★
: 💬 가족 누구도 집을 가져 본 적이 없어야 해요. 예전에 팔았어도 해당하지 않아요.
: 세대원 모두 지금까지 한 번도 집을 가져 본 적이 없는 상태입니다. "지금 무주택"보다 엄격합니다. 예전에 집이 있었다가 팔았으면 무주택이지만 생애최초는 아닙니다.
: 집각에서는: `household.everOwnedHome`이 `false`여야 합니다(구입자금 조건).

## 3. 소득과 자산

**부부합산 연소득** ★
: 💬 두 사람의 1년 소득을 더한 금액이에요.
: 신청인과 배우자의 1년 소득을 더한 값입니다.
: 집각에서는: `income.combined`. 둘 중 하나라도 모르면 합산값도 "모름"이 됩니다.

**1인 소득 기준 신청**
: 💬 합산 소득이 기준을 넘어도 신청인 혼자 소득이 기준 이하면 신청할 수 있어요. 금리는 조금 올라가요.
: 부부합산 소득이 기준을 넘더라도, 신청인 혼자의 소득이 별도 기준 이하이면 신청할 수 있게 해 주는 예외입니다. 대신 금리가 조금 올라갑니다.
: 집각에서는: 규칙의 `singleIncomeBasis` 정의입니다. 해당하면 결과에 "1인 소득 기준 적용" 안내가 붙습니다.

**순자산** ★
: 💬 가진 재산(집·예금·차 등)에서 빚을 뺀 금액이에요. 부부 것을 합쳐요.
: 가진 재산(부동산, 예금, 자동차 등)에서 빚을 뺀 금액입니다. 부부 둘의 순자산을 합쳐서 봅니다.
: 집각에서는: `assets.net`. 계산이 복잡해서 v1에서는 사용자가 직접 합산한 값을 입력받습니다.

## 4. 집

**전용면적** ★
: 💬 흔히 말하는 '평수'가 아니에요. 전용 84㎡가 보통 34평형이에요.
: 집 안에서 우리 가족만 쓰는 공간의 넓이입니다. 복도, 계단 같은 공용 부분은 빠집니다. 흔히 말하는 "34평"은 공급면적 기준이라 전용면적과 다릅니다(84㎡ 전용 ≈ 흔히 말하는 33~34평).
: 집각에서는: `purchase.areaM2`, `jeonse.areaM2`. 화면에서 ㎡로 입력받고, 평과 헷갈리지 않게 도움말이 필요합니다.

**수도권 / 수도권 외(지방)**
: 💬 수도권은 서울·인천·경기예요.
: 수도권은 서울·인천·경기입니다. 수도권 외 지역은 한도·금리 조건이 다른 경우가 많습니다.
: 집각에서는: `region.metro`

**규제지역** ★
: 💬 투기과열지구·조정대상지역이에요. 다른 지역보다 대출을 적게 해 줘요.
: 집값 과열을 막으려고 정부가 지정한 지역(투기과열지구, 조정대상지역)입니다. 대출을 더 적게 해 줍니다.
: 집각에서는: `region.regulated`. 구입자금 LTV에 영향을 줍니다.

**도시지역이 아닌 읍·면**
: 💬 읍·면 중 도시계획상 도시지역이 아닌 곳이에요. 면적 기준이 넓어져요.
: 행정구역상 읍·면이면서 도시계획상 도시지역이 아닌 곳입니다. 일부 상품은 이런 곳에서 면적 기준을 넓혀 줍니다.
: 집각에서는: `region.ruralTownship`

**매매가 / 담보 평가액**
: 💬 은행은 실제 거래가가 아니라 따로 매긴 평가액으로 심사해요.
: 매매가는 실제로 사고파는 가격이고, 담보 평가액은 은행이 그 집의 가치를 따로 매긴 값입니다. 두 값은 다를 수 있고, 대출 심사는 평가액을 봅니다.
: 집각에서는: 평가액을 입력받기 어려워 **매매가를 평가액으로 간주**합니다(`purchase.price`).

**임차보증금(전세금)**
: 💬 전세로 들어갈 때 집주인에게 맡기고 나중에 돌려받는 돈이에요.
: 전세로 들어갈 때 집주인에게 맡기는 돈입니다. 계약이 끝나면 돌려받습니다.
: 집각에서는: `jeonse.deposit`

**신규계약 / 갱신계약**
: 💬 새 집에 들어가는 계약과 살던 집을 연장하는 계약이에요.
: 새 집에 처음 들어가는 계약과, 살던 집의 계약을 연장하는 계약입니다. 갱신은 보증금이 오른 만큼만 추가로 빌릴 수 있습니다.
: 집각에서는: v1 한도는 신규계약 기준으로만 계산합니다.

## 5. 대출 한도

**대출 한도**
: 💬 여러 기준으로 계산한 금액 중 가장 작은 값이 한도예요.
: 빌릴 수 있는 최대 금액입니다. 정책 대출은 보통 여러 기준을 각각 계산해 **그중 가장 작은 값**을 한도로 합니다.
: 집각에서는: 규칙의 `limit.caps` 각각을 계산해 최솟값을 씁니다.

**호당 한도**
: 💬 집값과 상관없이 집 한 채당 빌릴 수 있는 최대 금액이에요.
: 집 한 채(1호)당 빌려줄 수 있는 상한 금액입니다. 집값이 아무리 비싸도 이 금액을 넘지 않습니다.
: 집각에서는: `perHousehold` cap

**LTV (Loan To Value, 담보인정비율)** ★
: 💬 집값 대비 빌릴 수 있는 비율이에요. 70%면 5억 집에 최대 3.5억이에요.
: 집값 대비 빌릴 수 있는 비율입니다. LTV 70%면 5억짜리 집으로 최대 3.5억까지 빌릴 수 있습니다.
: 집각에서는: `ltv` cap = 매매가 × 비율

**DTI (Debt To Income, 총부채상환비율)**
: 💬 1년 소득 중 대출 갚는 데 쓰는 돈의 비율이에요.
: 1년 소득 대비 1년에 갚는 대출 원리금 비율입니다. 소득에 비해 빚을 너무 많이 갚게 되지 않도록 막는 기준입니다.
: 집각에서는: 다른 대출의 상환액을 입력받지 않으므로 계산하지 않고 "직접 확인할 항목"으로 안내합니다.

**선순위채권**
: 💬 그 집에 먼저 잡혀 있는 빚이에요. 그만큼 한도가 줄어요.
: 그 집에 이미 잡혀 있는 다른 담보 대출입니다. 먼저 잡힌 빚만큼 새 대출 한도가 줄어듭니다.
: 집각에서는: 0으로 가정합니다(안내 문구로 표시).

**소요자금 비율**
: 💬 필요한 돈 중 빌릴 수 있는 비율이에요.
: 실제로 필요한 돈 대비 빌릴 수 있는 비율입니다. 예를 들어 전세금의 일정 비율까지만 빌려줍니다.
: 집각에서는: 전세자금의 `depositRatio` cap

## 6. 금리

**기본금리**
: 💬 소득과 대출기간(또는 보증금)으로 정해지는 출발 금리예요.
: 소득 구간, 대출기간(또는 보증금) 표에서 정해지는 출발 금리입니다.
: 집각에서는: `rate.table`

**가산 / 인하**
: 💬 조건에 따라 기본금리에 더하거나 빼는 금리예요.
: 조건에 따라 기본금리에 더하거나 빼는 값입니다(예: 지방 주택 인하, 1인 소득 기준 가산).
: 집각에서는: `rate.adjustments`. 결과의 `baseRate`에 포함됩니다.

**우대금리** ★
: 💬 자녀·청약저축 등으로 금리를 깎아 줘요. 깎을 수 있는 최대치가 있어요.
: 자녀가 있거나 청약저축을 오래 넣었으면 금리를 깎아 주는 혜택입니다. 항목별로 하나씩만 받고, 다 더해도 상한을 넘지 못합니다.
: 집각에서는: `rate.discounts`, 상한은 `rate.discountCap`

**최종금리 하한**
: 💬 우대를 많이 받아도 이보다 낮아지지 않아요.
: 우대를 아무리 많이 받아도 이보다 낮아지지 않는 최저 금리입니다.
: 집각에서는: `rate.floor`

**%p (퍼센트포인트)** ★
: 💬 3.0%에서 0.3%p 내리면 2.7%예요.
: 금리 차이를 나타내는 단위입니다. 3.0%에서 0.3%p 내리면 2.7%입니다(0.3%를 깎는 것과 다릅니다).

**변동금리 / 고정금리**
: 💬 변동금리는 대출 중간에 바뀌고, 고정금리는 정해진 기간 동안 그대로예요.
: 변동금리는 시장 금리에 따라 대출 중간에 바뀌고, 고정금리는 정해진 기간 동안 그대로입니다.
: 집각에서는: v1은 금리 방식별 가산을 반영하지 않고 기본금리 기준 범위만 보여 줍니다.

**청약저축(주택청약종합저축)**
: 💬 아파트 청약을 위해 매달 넣는 저축이에요. 오래 넣으면 금리 우대를 받을 수 있어요.
: 새 아파트 분양(청약)을 받으려고 매달 넣는 저축입니다. 가입 기간과 납입 횟수가 많으면 대출 금리 우대도 받을 수 있습니다.
: 집각에서는: `subscription.years`, `subscription.paymentCount`

## 7. 기타 조건

**중복대출 금지** ★
: 💬 이미 기금 대출이나 은행 주택 대출을 쓰고 있으면 받을 수 없어요(예외 있음).
: 이미 정책 대출이나 은행 주택 관련 대출을 받고 있으면 새로 받을 수 없다는 조건입니다. 예외가 있습니다.
: 집각에서는: `household.hasFundLoan`, `hasMortgageLoan`, `hasJeonseLoan`

**공공임대주택**
: 💬 정부·공공기관이 싸게 빌려주는 집이에요. 살고 있으면 전세대출이 제한돼요.
: 정부·공공기관이 시세보다 싸게 빌려주는 임대주택입니다. 이미 혜택을 받고 있어서 전세대출을 제한합니다.
: 집각에서는: `household.livesInPublicRental`

**매매·임대차 계약 체결** ★
: 💬 자격 판정에는 필요 없어요. 계약을 맺은 뒤 은행에 신청할 때 필요해요.
: 집을 사거나 전세로 들어가기로 집주인과 계약서를 쓰는 것입니다. 전세는 보증금의 일부(계약금)도 내야 신청할 수 있습니다.
: 집각에서는: 판정 상태에 넣지 않고, 계약 전이거나 모르면 결과에 안내 문구를 붙입니다(D-15).

**부동산 전자계약**
: 💬 종이 대신 온라인으로 맺는 부동산 계약이에요.
: 종이 대신 정부 시스템에서 온라인으로 맺는 부동산 계약입니다. 금리 우대 대상입니다.
: 집각에서는: v1은 입력받지 않습니다.

**주민등록등본**
: 💬 누가 함께 사는지 증명하는 서류예요.
: 세대 구성(누가 같이 사는지)을 증명하는 서류입니다. 예비부부는 대출 후 배우자가 함께 등재된 등본을 내야 합니다.

## 8. 집각 결과 화면 용어

**가능 / 확인 필요 / 불가** ★
: 💬 가능은 모든 조건 충족, 확인 필요는 모르는 입력이 있음, 불가는 맞지 않는 조건이 있음이에요.
: 엔진의 판정 상태(`eligible` / `needs_check` / `ineligible`)입니다. 조건 하나라도 맞지 않으면 "불가", 맞지 않는 건 없지만 모르는 입력이 있으면 "확인 필요", 전부 맞으면 "가능"입니다.

**직접 확인할 항목**
: 💬 신용도처럼 입력으로 알 수 없어 은행에서 직접 확인해야 하는 조건이에요.
: 엔진이 판단하지 않고 항상 보여 주는 안내입니다(`manualChecks`). 신용도처럼 입력으로 알 수 없는 조건이라 상태에는 영향을 주지 않습니다.

**판정 기준일**
: 💬 혼인기간 같은 날짜를 계산하는 기준 날짜예요. 보통 오늘이에요.
: 혼인기간 같은 날짜 계산의 기준이 되는 날짜입니다(`asOf`). 보통은 오늘입니다.

**예상 한도 / 예상 금리** ★
: 💬 입력값으로 계산한 추정치예요. 실제 값은 은행 심사로 정해져요.
: 입력값으로 계산한 추정치입니다. 실제 값은 은행 심사(평가액, 신용, 보증 등)에 따라 달라집니다.
